# かずのにわ

5歳から学年に縛られず学ぶ、タブレット向け算数・国語Webアプリ。

## ファイル
- `dist/index.html`: HTML・CSS・JavaScriptをまとめたアプリ本体。ビルド・外部依存なし。
- `.openai/hosting.json`: 現在のSites配信先の設定。

## 機能
算数13コース（数える、大小比較、加減算、乗除算、分数）と国語8コース・64問（ひらがな、ことばの穴埋め、カタカナ、反対語、漢字、助詞、短文読解、順序・理由の読解）、日本語読み上げ、1セット5問、適応出題、2人分の学習記録、JSONバックアップと復元。

## 保存と実行
学習記録は同一端末・同一ブラウザのlocalStorageに保存。サーバー同期はありません。JSONバックアップには利用者名と学習記録が含まれるため、Gitには追加しないでください。
静的Webサーバーでdistを配信します。Android Braveを想定していますが、実機表示・音声は未確認です。

## 起動画面・育成（2026-10-20）
- 名前選択ダイアログ、毎日のおすすめ3ステージ、コイン、キャラクター「にわっち」の5段階成長、6種類の着せ替えを追加。
- 各コースの当日初回クリア10コイン、以降3コイン。正答数やヒント利用によらず5問終了で付与。おやつ10コイン、3回で1レベル。休止による減点・課金なし。
- 子どもごとにコイン・所持品・装備・成長を保存。既存localStorageキーと学習記録を維持。既存JSONバックアップに育成情報も含まれる。
- BGMはオリジナルのWeb Audio旋律。起動直後に再生を試し、自動再生が制限された場合は名前選択画面の音楽ボタンから開始。自動再生を保証するものではない。バックグラウンドでは停止。
- 追加ソース: dist/game.js, dist/game.css。移行・付与・二重付与防止・残高不足・着脱・成長・利用者分離をテスト済み。実機の音声・描画は未確認。
