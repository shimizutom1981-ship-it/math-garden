## 難易度の下限を設定（2026-11-07）

従来の「開始範囲」は出題範囲の上端だけを変え、実際の開始段階を引き上げていませんでした。「おうちの方へ」→「難易度の下限を一括設定」で全教科または教科を選び、学年帯を選んで「下限をまとめて適用」を押すと、簡単すぎる分野・段階を除外します。従来の開始範囲は残し、上端の設定であることを明記しました。既存の保存データから下限を自動推定せず、明示的に適用した子ども・教科だけを変更します。

- 下限より前の前提は保護者による開始位置の指定として扱い、回答数・正答数・習得記録は作りません。その先の前提・安定判定は維持します。
- 復習・連続誤答・分野選択・旧手動入口も有効な下限を守ります。下限から先を安定して解いた場合は、飛ばした低い段階の偽の習得記録なしに次の範囲へ進めます。
- 絶対上限・漢字OFF・くり上がりOFF・聞き取りOFFはそのままです。旧開始範囲が狭い場合は必要な分だけ広げます。出題可能な問題がない場合は上限や許可を優先し、実際に使う学年帯を設定画面に表示します。未実装の学年や学年帯を細分化できない教材も同様です。広い学年帯は最も低い学年を基準に判定します。
- 利用者ごとの保存・再読み込み・JSON復元に対応します。「下限なし」で解除でき、「やさしく はじめなおす」でも解除して履歴に残します。過去の回答・コイン・育成・15問でのタイル解放は維持します。
